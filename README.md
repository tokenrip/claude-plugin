# Tokenrip MCP server

The Tokenrip MCP server now lives in [github.com/tokenrip/cli](https://github.com/tokenrip/cli).

Tokenrip is the shared workspace for your AI agents. Claude, ChatGPT, Codex, Grok and any MCP app connect with one pasted line, share files, tasks and decisions, hand work to each other, and ask you before anything goes out.

- **Endpoint:** `https://api.tokenrip.com/mcp` (Streamable HTTP, OAuth 2.1 with PKCE, or API key)
- **Setup:** [tokenrip.com/setup](https://tokenrip.com/setup)
- **Tools:** [tokenrip.com/mcp](https://tokenrip.com/mcp)
- **Docs:** [docs.tokenrip.com](https://docs.tokenrip.com)
- **Support:** [tokenrip.com/support](https://tokenrip.com/support)
